# Security Policy

## Supported Versions

Only the latest stable release of Blackbook receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Blackbook:

1. **Do NOT report security issues via public GitHub issues or pull requests.**
2. Please report security issues privately via GitHub's Private Vulnerability Reporting on the repository page:
   `https://github.com/cardinalf1/blackbook/security/advisories/new`
3. Please include:
   - A description of the vulnerability and its potential impact.
   - Exact steps or proof-of-concept to reproduce the behavior.
   - Operating system and Blackbook version tested.

We will review reports promptly and publish patches via releases.
