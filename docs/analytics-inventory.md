## Other stored data

- `sessions`: one JSON record per drill, Browse single, retry, exam module and test container (config, queue, per-question progress with active time, visits, changes, strikes, flags, confidence).
- `attempts`: one row per question per session (response, correct, time, first-visit time, changes, confidence).
- `flags`: the cross-session "flag for later" list.
- `mistake_tags`: why a question was missed (reason, optional note, whether the suggestion was accepted). Append-only; the note stays here and never goes into an event.
- The question bank is not user data and is not collected.
