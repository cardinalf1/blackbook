# Getting a Free Groq API Key for AI Coaching

Blackbook can provide instant AI question explanations, hint progressions, and personalized weak-area drills using fast LLM inference powered by Groq.

Blackbook has no central servers and never proxies your AI calls. You provide your own API key directly to call Groq's official API (`api.groq.com`).

## Is It Free?
Yes. Groq offers a generous free tier with high rate limits that are more than sufficient for everyday SAT study and practice.

## Step-by-Step Instructions

1. **Sign up or Log in**:
   - Visit the [Groq Console](https://console.groq.com).
   - Sign up using your Google, GitHub, or email account.

2. **Generate an API Key**:
   - In the left sidebar or top navigation, click **API Keys** (or go to `https://console.groq.com/keys`).
   - Click the **Create API Key** button.
   - Enter a name (e.g. `Blackbook`) and click **Submit**.
   - Copy the generated key (it starts with `gsk_...`). **Important:** Copy it immediately, as Groq will only display it once.

3. **Add the Key to Blackbook**:
   - Open Blackbook and click **Settings** (or press the Settings icon).
   - Scroll down to the **AI Explanations & Coaching** section.
   - Paste your key into the **Groq API Key** input field.
   - Click **Save Key**. Blackbook will securely test the connection and report success.

## Privacy & Security
- Your key is encrypted using your operating system's secure credential storage and kept strictly on your local disk in your user data directory.
- It is never transmitted anywhere other than direct HTTPS requests to `api.groq.com`.
- You can remove your key at any time by clicking **Remove Key** in Settings.
