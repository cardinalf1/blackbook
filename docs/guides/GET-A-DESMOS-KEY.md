# Getting a Desmos API Key for the Math Calculator

Blackbook features an authentic test room environment, including the real embedded Desmos graphing and scientific calculator during Math sections.

Because Desmos is a proprietary service by Desmos Studio PBC, each user embeds it in Blackbook using their own Desmos API key.

## Step-by-Step Instructions

1. **Request an API Key**:
   - Visit [Desmos Studio API](https://www.desmos.com/api).
   - Sign up or request an API key for non-commercial or personal educational practice.
   - Desmos will provide you with an API key string (e.g. `dcb317...`).

2. **Add the Key to Blackbook**:
   - Open Blackbook and navigate to **Settings**.
   - Scroll to the **Desmos Calculator** section.
   - Paste your Desmos API key into the field.
   - Click **Save Key**. Blackbook will run a quick verification test.

3. **Using the Calculator in Math**:
   - Once saved, the Desmos calculator icon appears in the top toolbar during all Math practice drills and exams.
   - You can drag, resize, toggle between Graphing and Scientific modes, or reset the keypad at any time.

## Privacy & Security
- Your Desmos key is stored encrypted on your local computer.
- When opening the calculator, Blackbook loads the official script from `www.desmos.com` with your key in a sandboxed frame.
- No question content, answers, or study history are ever sent to Desmos.
