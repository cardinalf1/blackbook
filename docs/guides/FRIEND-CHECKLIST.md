# Friend Sharing & Quick Setup Checklist

If you are sharing Blackbook with a friend or classmate, use this 2-minute checklist to get them started with zero hassle:

## Checklist for You (The Sender)
1. [ ] **Export your Question Bank Zip**:
   - Open Blackbook &rarr; click **Question bank** &rarr; click **Export Bank Zip**.
   - Save the `Blackbook-QuestionBank-<date>.zip` file (approx. 12 MB) to a USB thumb drive, AirDrop, or local file share.
   - *Note*: This zip contains only questions and answer explanations from the public repository. It contains **none** of your personal notes, scores, attempts, or API keys!
2. [ ] **Share the Installer**:
   - Give them the link to the [GitHub Releases](https://github.com/cardinalf1/blackbook/releases) or the `Blackbook-Setup-1.0.0.exe` installer file.

## Checklist for Your Friend (The New User)
1. [ ] **Install the App**:
   - Run the installer. On Windows SmartScreen, click *More info* &rarr; *Run anyway*.
2. [ ] **Import the Bank Zip**:
   - When Blackbook opens for the first time, click **Import Existing Backup**.
   - Select the `Blackbook-QuestionBank.zip` file you shared with them.
   - It will verify and import all ~3,700 questions in 3 seconds flat without waiting for any web download.
3. [ ] **Ready to Practice**:
   - Start practicing immediately with Full Practice, 20-Question Drills, or Math/RW by domain!
   - (Optional) If they want AI explanations or the Desmos calculator, follow the guides in `docs/guides/GET-A-GROQ-KEY.md` and `GET-A-DESMOS-KEY.md`.
